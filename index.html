🔑 Claude API

キーはこの端末のブラウザ内（localStorage）にのみ保存され、Claude以外には送信しません。共有端末では使用後に「キー削除」を。このバージョンで書き出すJSONにはキーを含みません（以前に書き出したファイルには入っていることがあります）。別の端末や、ブラウザのデータを消した後は、設定で入力し直してください。

キー取得: console.anthropic.com

🪪 自分の名刺（配る立場）

名刺交換のたびに「どの立場で配ったか」を記録・絞り込みでき、AIフォロー下書きの署名もその立場のプロフィールURLに自動で切り替わります。

✉️ 送信テンプレート

差し込みタグ: {氏名} {会社} {役職} {立場} {自分名} {プロフィールURL} {日付} {交換日} {会った理由} {面談内容} {相手のニーズ} {次にすること} は送信時に自動で置換されます（空の項目の行は自動で省かれます）。
